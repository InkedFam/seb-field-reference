# The Events Calendar Is on Hold

The Events Calendar is on hold until an appropriate solution can be reached. There are three possible solutions, however each is currently being blockaded.

## 1. Change how SEB handles event posts

Currently, SESH does not allow its iCalendar/Google Calendar sync to work when an event is created as a **Discord Forum Thread**, which is how our events are created presently.

For the website sync to work, SEB Command would need to post the SESH event in a normal **Discord Text Channel** that I can access. I could then sync it to a Google account with a calendar for SEB events, which the website could pull and display.

## 2. Buy the API Token

SESH offers a version of its bot for servers on the **Pro plan** that provides API access. This would be the easiest and simplest option, but the plan costs **$25 per month**.

## 3. Use of Sesh /link

This is not possible with how Sesh is used in the LSSD Discord. Per Biscuit, it would disrupt the faction.
